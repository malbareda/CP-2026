# 📦 `src` — Default package: els fonaments

[🏠 Índex general](../README.md)

Les classes que estan **directament a `src/`**, sense cap carpeta. Com que no són dins de cap package, **no porten la línia `package ...;`** a dalt de tot (Eclipse en diu *default package*).

Són els primers passos: l'estructura d'un programa, escriure per pantalla i les variables.

| `VariablesString` | [VariablesString.md](VariablesString.md) | Text i concatenació amb `+` |
